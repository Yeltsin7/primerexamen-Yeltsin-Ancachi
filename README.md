Descripción del Proyecto:
Este proyecto consiste en el desarrollo de una landing page para la empresa Manaco. La página está diseñada con un enfoque responsive, lo que significa que se adapta correctamente a diferentes tipos de dispositivos, tanto móviles como de escritorio.


Accesibilidad (a11y)

1. Se agregó un enlace “Saltar al contenido principal” (skip link) para que los usuarios de teclado o lectores de pantalla puedan ir directamente al contenido.  
2. Se añadio atributos "alt" descriptivos en imágenes de los productos para facilitar la navegacion a usuarios con lectores de pantalla.  
3. Se definió un foco visible en enlaces y botones, para que sea claro qué elemento está activo al navegar con teclado.  
4. El atributo "aria-label" se uso en la navegación principal para poder mejorar la comprensión para tecnologías de asistencia.  
5. Se probó la navegación con teclado tab, shift+tab para garantizar que todas las funciones sean accesibles.
